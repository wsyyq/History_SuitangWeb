# 候选问题与回顾问答索引

## 第四阶段实现索引（不改变下文证据状态）

`js/question-data.js` 从既有四级组关联的题干建立静态映射，全部答案/解释保持 pending。对应为：two-capitals→Q02；granaries→Q03；canal→Q04/Q05/Q06；goguryeo→Q07/Q08；sui-burden→Q09；economy→Q11；relations→Q12/Q13；map-reading→Q14；perspectives→Q15；concepts→Q16；impact→Q18/Q19；fanzhen-flow→Q20/Q21；five-flow→Q23。共 13 组、19 条题干。Q01/Q10/Q17/Q22 不因实现交互而新增入口，继续属于课标或三级教学资料。

分组沿用已验收入口，仍是可逆的预备题序，尤其 canal 的合链待教师复查。Q23 网页题干采用中性问法“什么是五代十国？它与唐末藩镇割据有何联系？”，对应原框架“五代十国：本质是藩镇割据的延续”，不把待核的解释预置为结论。R01—R04 保留二级同时展示题目与答案占位，稳定数据入口为 `LESSON.reviewItems`。下文素材记录及所有审核结论保留不变。

这是素材草案，不是完整脚本、最终文案或页数。所属菜单 ID 见 [教学树](lesson-outline.md)，T 编号见 [教材索引](textbook-map.md)，A 编号见 [审核表](historical-fact-audit.md)。

呈现类型：“四级逐步揭示（候选）”仅表示如教师采用问题链时按问题→答案→下一题；不是强制把所有三级解释升级。Q01 是课标入口预备素材；Q10、Q17、Q22、Q23 等也可保留三级讲解，不因此新增四级页面。所有答案的未决部分只作待确认占位。回顾 R01—R04 直接显示问题和答案，与对应原题共享证据状态。
