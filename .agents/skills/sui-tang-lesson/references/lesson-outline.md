# 课堂结构与导航契约

依据：框架全文及 MX-T01 第 3 节。总时长 40 分钟已确定；各模块分钟数、最终交互页数不在本阶段确定，时间分配留至第四阶段教师确认。下列 ID 是索引，不是实际页面。

## 一级与公共导航

一级顺序：L1-1 课堂标题《从隋唐盛世到五代十国》与插图 → L1-2 课标要求 → L1-3 课堂脉络。插图待选、课标图缺失。二级是以下 M1—M6，顺序固定。

通常二级选项进入所属三级，完成后回到所属二级；三级显示对应教材段落截图，确有问题链处才用下划线/热点进入四级，无四级则停留三级。四级依次“显示问题 → 再点击显示答案/解释 → 再点击下一问题”，可回上一页并一键返回所属三级。常规各级保留返回上一级、本级下一页、进入下一级的导航意图；没有目标则禁用或隐藏，末题出口需后续明确，不造失效点击区。

所有层级均需移动、放大、点选、绘画模式；画笔换色、撤销、橡皮等第三阶段实现。此处仅记录需求，无实现代码。

## 必须保留的特殊规则与未决项

- M6 四项直接呈现问题答案，不显示教材段落，不设常规四级逐步揭示。它们是 M6 的二级内容，不能擅自把主模块由六个改成九个；具体如何承载四项、如何返回主脉络由教师确认。
- 隋兴盛中的“运河作用—整体联系—重心南移”（Q04—Q06）可合成一链或拆分；候选 QID 数量不等于最终页数。
- M1 与 L1-2 是否共用课标页、L1-3 与二级脉络的转入方式，框架未明确，不自行设计。
- M6 直接问答与全局点选揭示若冲突，优先保留特例并待教师确认，不静默套用统一机制。
- 原框架“两京制”“按守城”“现在中国有没有当前领土”等原意和疑点见审核 A01、A02、A08；保留教学位置并不代表确认答案。
