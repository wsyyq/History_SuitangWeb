# 第6课《从隋唐盛世到五代十国》教案

## 一、课题名称

**课题：**第6课《从隋唐盛世到五代十国》
**教材：**统编普通高中历史必修教材《中外历史纲要（上）》
**授课对象：**高一年级学生
**课型：**新授课
**课时：**1课时，40分钟

## 二、教学目标

本课依据《普通高中历史课程标准（2017年版2020年修订）》必修课程相关要求，重点引导学生认识隋唐时期的社会繁荣、民族交融与区域开发。制度、思想文化等内容结合教材后续课次作必要联系，不在本课展开专题教学。[课程标准官方发布机构下载页](https://www.ictr.edu.cn/download_center/put.html)

本课突出时空观念、史料实证和历史解释，将唯物史观与家国情怀融入具体学习活动。

| 教学目标 | 学习表现与评价依据 |
|---|---|
| 梳理隋唐至五代十国的历史发展脉络，形成基本的时空认识。 | 能在时间轴上准确标注581年、589年、618年、755年、763年和907年，并说明相应事件；能结合地图指出长安、洛阳及相关民族活动的大致方位。 |
| 运用教材文字、历史地图和器物图片，说明隋唐繁荣的主要表现及形成原因。 | 能从大运河、曲辕犁、唐三彩等材料中提取有效信息，列举至少两项史实支持自己的解释，区分材料直接反映的信息与进一步推论。 |
| 分析隋朝灭亡与唐朝盛衰变化，理解政治治理、社会生产和民众负担之间的联系。 | 能分别说明隋亡与安史之乱的主要原因，并用因果关系解释安史之乱对中央权力、边疆形势和社会经济的影响，避免单一原因解释。 |
| 认识各民族交往交流交融及共同开发边疆的历史作用。 | 能结合突厥、回纥、吐蕃、靺鞨的相关史实，概括战争、合作、册封、和亲、会盟等交往方式，说明各民族共同参与统一多民族国家发展的历史进程。 |

## 三、教学内容

### （一）知识结构与教学主线

本课围绕“统一与建设—繁荣与交融—转折与分裂”展开，按照现有课堂顺序组织六个模块：

**课标研读—隋朝兴亡—唐朝繁荣与民族交融—安史之乱—唐朝灭亡与五代十国—内容回顾。**

通过隋唐兴衰的具体史实，引导学生认识：国家统一、合理治理、生产发展和各民族交往有助于社会繁荣；过度征发、政治失序与战争会损害社会生产和国家治理。王朝更替与社会发展既有变化，也存在延续。

### （二）教学实施与时间安排

| 教学环节 | 时间 | 教师活动与主要内容 | 学生活动及即时评价 |
|---|---|---|---|
| 课标研读与导入 | 3分钟 | 展示课程标准及大运河图片，联系前课三国两晋南北朝的政权分立与民族交融，提出贯穿全课的问题：“隋唐何以走向繁荣，又为何发生盛衰转变？”说明本课学习线索。 | 回顾前课知识，指出本课需要关注统一、繁荣、民族交往和盛衰变化。教师据此判断学生已有认识。 |
| 隋朝：统一、建设与短暂统治 | 8分钟 | 用时间轴区分581年建隋与589年统一；结合长安、洛阳、仓储和运河示意图，讲解国家建设及南北联系。围绕运河作用、运河功过和秦隋比较组织问题学习，结合教材分析隋亡原因。经济重心南移以四阶段简表作纵向联系。 | 阅读教材并圈画依据；从政治、经济、文化角度分析交通建设的作用；比较工程的长期效益与修建过程中的社会代价。能区分建国与统一，能用材料支持评价。 |
| 唐朝：繁荣、民族交融与区域开发 | 13分钟 | 说明618年唐朝建立及此后的统一过程；梳理贞观之治、武则天当权时期和开元盛世。运用曲辕犁、唐三彩图像，引导学生分析经济发展与盛世成因。结合669年教材地图和相关正文，讲解各民族交往及边疆开发。 | 提取治理措施和经济发展的证据；在地图上定位突厥、回纥、吐蕃、靺鞨，归纳交往方式。回答时做到“对象明确、方式准确、史实对应”，并注意地图年代。 |
| 安史之乱：由盛转衰 | 7分钟 | 组织学生从政治变化和军事力量配置等方面分析原因，概述755—763年的过程，展示影响的因果联系。进一步讨论藩镇割据与中央权力的关系。 | 完成“原因—过程—影响”提纲，区分直接后果与较长期变化；结合教材说明唐朝由盛转衰，避免把“由盛转衰”等同于立即灭亡。 |
| 唐朝灭亡与五代十国 | 6分钟 | 运用时间线讲解黄巢起义、朱温掌权及907年废唐建梁；结合地图区分五代与十国，联系唐末藩镇割据，说明分裂格局的形成与延续。 | 按时间排序关键事件，准确区分“五代先后更替”与“十国在不同地区、不同时间存在”，说明唐末至五代十国的政治联系。 |
| 内容回顾与课堂评价 | 3分钟 | 同时呈现原有四项回顾问题及答案，组织快速复述与辨析，回扣本课主线。教师根据回答作针对性反馈。 | 用简洁语言概括交通建设作用、经济重心南移阶段、关系类问题的分析方法及民族边疆关系与对外关系的辨析原则。 |

**时间控制：**隋朝模块以基础梳理2分钟、仓储与运河问题4分钟、隋亡及秦隋比较2分钟组织；唐朝模块以建立与繁荣5分钟、盛世成因2分钟、民族关系与地图阅读6分钟组织。现有15道问题采用即时问答、读图判断和教师归纳相结合的方式，不逐题开展长时间讨论。

### （三）关键问题的教学处理

**1. 如何评价隋朝大运河？**

引导学生分别考察工程的历史作用与建设过程中的社会代价。运河沟通南北，有助于巩固统一、促进经济交流和沿岸城市发展；同时，隋炀帝时期多项工程与战争造成沉重负担，破坏生产并激化社会矛盾。

要求学生避免将隋亡全部归因于运河，也不能因运河具有长期价值而忽视当时民众的负担。文化交流方面的认识作为联系交通功能作出的课堂分析，与教材直接表述加以区分。

**2. 秦、隋有哪些相似之处？**

从统一、建设与制度影响、短期统治及灭亡原因三个方面进行比较。重点在于训练学生依据共同标准组织史实，不将“二世而亡”等概括作为精确统计全部继位者的结论。

**3. 隋唐盛世形成的原因是什么？**

结合教材，从国家统一、统治者的治理措施、生产工具改进、经济恢复发展及民族交往等方面组织解释。三省六部制、科举制等作为联系后续制度史学习的提示，不在本课展开制度沿革，也不将其形成与发展压缩为同一时间点。

**4. 如何阅读669年教材地图？**

先读图题、年代和图例，再辨认地名、民族活动方位与政权关系。将地图与正文中的具体事件相互参照，特别注意图中的后置年代注记，不能把全部事件看作669年同时发生，也不能把民族名称的标注范围直接等同于疆界或唐朝直接管辖范围。

**5. 如何理解安史之乱及藩镇割据？**

从中央权力削弱、边疆形势变化、北方经济受损等方面分析安史之乱的影响。联系长期发展过程说明南方经济地位上升，不将经济重心南移解释为某次战争发生后的即时结果。

对藩镇的分析应区分不同地区和时期：部分藩镇挑战中央权力，也有藩镇在一定条件下承担军事、财政等职能；不能把所有藩镇一概而论。

### （四）四项课堂回顾

1. **修路、修运河的作用：**根据材料，从政治联系、经济交流、人员往来与文化交流等角度分析，做到结论与证据对应。
2. **经济重心南移的阶段：**魏晋以前经济重心主要在北方；魏晋南北朝时期江南逐步开发；安史之乱后南方经济地位进一步上升；至南宋时期经济重心南移完成。靖康之变作为联系南宋的历史节点，不作为南移完成的瞬时时点。
3. **关系类问题的分析方法：**分别考察双方状况、双方互动及有材料支持的其他因素，不机械凑足固定条目。
4. **民族边疆关系与对外关系的辨析：**依据教材分类，结合当时的政权关系、治理方式与具体历史情境判断，不能仅以今天的国界作唯一标准。

## 四、重、难点分析

### （一）教学重点

**1. 隋唐统一与社会繁荣的表现及原因。**

确立依据：这一内容直接回应课程标准，是理解本课历史阶段特征的基础。

突破思路：以大运河、曲辕犁、唐三彩等具体材料为支点，将治理措施、生产发展和社会繁荣联系起来，形成“史实—证据—解释”的学习路径。

**2. 唐朝民族交往与统一多民族国家的发展。**

确立依据：民族交融与区域开发是本课所属单元的重要主题。

突破思路：将历史地图与教材正文结合，组织学生完成“民族或政权—活动方位—交往方式—具体史实”的对应，突出各民族的共同作用。

### （二）教学难点

**1. 对历史事件作多角度、有条件的评价。**

学生容易将复杂问题归结为单一人物或单一事件，也容易把工程的长期效益与当时的社会代价混为一谈。

突破思路：以大运河功过和隋亡原因为例，引导学生区分评价对象、时间范围和证据来源，再形成有依据的结论。

**2. 理解唐朝由盛转衰与五代十国之间的联系。**

学生容易停留在事件记忆层面，难以理解中央与地方权力变化、战争破坏和政权分裂之间的关系。

突破思路：运用时间轴与因果关系图，将安史之乱、藩镇割据、唐末动荡和五代十国分裂格局联系起来，同时保留不同地区、不同阶段的差异。

## 五、教材、学情分析

### （一）教材分析

本课位于《中外历史纲要（上）》第二单元“三国两晋南北朝的民族交融与隋唐统一多民族封建国家的发展”，主要包括“隋朝兴亡”“唐朝的繁荣与民族交融”“安史之乱、黄巢起义和五代十国”等内容。

本课上承三国两晋南北朝的政权分立、民族交融与江南开发，下接隋唐制度变化、文化发展及此后辽宋夏金元时期的历史。教学既要呈现隋唐盛衰的基本过程，也要为后续专题学习建立时空框架。

教材正文提供基本史实，地图帮助理解空间联系，器物图片和“学思之窗”等栏目为观察、比较与评价提供材料。教学应根据学习目标组合使用这些资源，避免将所有栏目都处理为同等深度的知识讲授。这也符合统编教材通过不同栏目支持知识学习与历史思考的编写思路。[教育部《普通高中历史教材介绍》](https://www.moe.gov.cn/fbh/live/2019/51084/sfcl/201908/t20190827_395978.html)

### （二）学情分析

本教案按普通高一学生的一般学习基础设计，具体实施时需结合课前提问进行调整。

学生在初中阶段通常已经接触隋唐统一、大运河、贞观之治、开元盛世和安史之乱等内容，具备一定的事件记忆和图片识读能力，但可能存在以下问题：

- 容易混淆王朝建立、全国统一和盛世形成的时间。
- 能列举人物与事件，尚不善于解释事件之间的联系。
- 容易把教材结论直接用于答题，缺少寻找材料依据的意识。
- 容易以现代疆域或单一标准解释古代复杂的民族、政权关系。
- 容易将江南开发、经济重心逐渐南移和南移完成视作同一概念。

因此，课堂采用时间轴、地图定位、问题递进和即时反馈，帮助学生由知识识记逐步转向有依据的历史解释。

## 六、教学方法

| 教学方法 | 具体运用 |
|---|---|
| 讲授法 | 精要说明隋唐建立、统一、盛衰及五代十国的基本过程，对跨课知识作必要提示，保证40分钟课堂的完整性。 |
| 史料研习法 | 围绕教材正文、皮日休诗、地图及器物图片，指导学生辨认材料类型、提取信息、寻找依据，区分史实与解释。 |
| 问题探究法 | 依托现有课堂问题，按照“呈现问题—学生判断并举证—揭示答案—返回教材核对”的顺序组织学习，避免直接展示答案代替思考。 |
| 比较法 | 运用秦隋比较、隋唐治理比较及不同民族交往方式比较，帮助学生建立明确的比较标准。 |
| 图示教学法 | 用时间轴呈现先后关系，用地图说明空间关系，用因果关系图解释安史之乱及唐末政治变化。 |
| 短时讨论与形成性评价 | 对大运河评价、盛世成因等问题安排简短交流；以能否准确提取史实、提出证据并合理解释作为反馈依据。 |

评价重点放在学生是否能够准确使用史实、联系材料作出解释，以及能否识别时间、空间和因果关系上的常见混淆。
